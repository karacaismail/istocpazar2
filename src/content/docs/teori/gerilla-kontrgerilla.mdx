## Elinizdeki çalışmanın değeri

Daha önce ürettiğiniz kontrgerilla pazarlama çerçevesi — olay ontolojisi, karşılık merdiveni,
ECA+ kural dili, amplifikasyon bütçesi, ortogonal cevap kuralı — **ciddi ve kullanılabilir bir
çalışmadır**. Rehber onu reddetmiyor; sırasını tartışıyor.

<Aside type="caution" title="Tek cümlelik değerlendirme">
Kontrgerilla, **rakibin size saldırdığı** bir dünyanın disiplinidir. İstoc'un bugünkü
problemi ise kimsenin İstoc'a saldırmıyor olmasıdır — çünkü henüz kimse farkında değil.
Savunma sistemi kurmadan önce savunulacak bir mevzi gerekir.
</Aside>

## Gerilla pazarlamanın gelişimi

<Tag tone="warn" icon="lightbulb">Kanıt: yayın tarihçesi, uzman görüşü</Tag>

| Dönem | Yapı | Eklenen düşünce |
| ----- | ---- | --------------- |
| 1984 | 3 temel ilke | Bağlılık, yatırım, tutarlılık |
| 1993 | 10 ilke | Güven, sabır, araç çeşitliliği, satış sonrası, kolaylık, şaşırtma, ölçüm |
| 2007 | 16 ilke | Katılım, karşılıklı bağımlılık, teknoloji, izin, içerik, sürekli geliştirme |
| 2010'lar | Akademik sınıflandırma | Sürpriz, yayılım, maliyet etkinliği; ambient, buzz, viral, ambush alt türleri |
| 2020'ler | Platformlaşmış gerilla | Sosyal medya, topluluk, gerçek zamanlı içerik, algoritmik yayılım |

**Buradan çıkan asıl ders:** Sürpriz artık sıra dışı değil, sektör standardı. Herkesin sıra
dışı olduğu bir ortamda sıra dışılık ayırt edici olmaktan çıkar. Bu, sizin başlangıçtaki
sezginizin doğru olduğunu gösterir.

## Kontrgerilla çerçevesinin özgün katkısı

Yaptığınız çalışmada gerçekten yeni olan, "kontrgerilla" adı değil; şu dört unsurun bir arada
tanımlanmasıdır:

1. **Cevap vermemeyi meşru bir strateji saymak** (L0 ve L1 seviyeleri).
2. **Ortogonal cevap kuralı** — aynı araçla misilleme yapmamak.
3. **Amplifikasyon bütçesi** — cevap verirken rakibe kazandırılan erişimi hesaplamak.
4. **Kapasite kapısı** — talep artıran hamleyi, operasyon yetmiyorsa başlatmamak.

<Aside type="tip" title="Savunulabilir iddia">
"Kontrgerilla pazarlama terimini ilk kullanan kişi" iddiası savunulamaz. Ancak
"rekabetçi dikkat olaylarını, cevapsızlığı da içeren kademeli bir karşılık merdiveni ve
makinece uygulanabilir kural diliyle sistemleştiren ilk açık çerçevelerden biri" iddiası
savunulabilir. Fark, iddianın **mekanizmaya** dayanmasıdır.
</Aside>

## Komşu disiplinlerle farkı

| Disiplin | Ne yapar | Kontrgerilladan farkı |
| -------- | -------- | --------------------- |
| Rekabetçi karşılık | Rakip hamlesine cevap verir | Genellikle aynı araçla misilleme yapar |
| Ambush pazarlama | Sponsor olunmayan etkinlikten yararlanır | Yalnızca etkinlik bağlamı |
| Anti-ambush | Sponsorun haklarını korur | Salt savunma, yeni değer üretmez |
| Countermarketing | Zararlı ürünün talebini azaltır | Halk sağlığı bağlamı |
| Demarketing | Fazla talebi azaltır | Rakip hamlesini avantaja çevirmez |
| Aşılama / prebunking | Kitleyi önceden hazırlar | Savunmanın yalnızca bir parçası |
| Kriz iletişimi | İtibar krizini yönetir | Fırsat ve dikkat transferini kapsamaz |

## İstoc için ne zaman uygun

| Koşul | Sağlanıyor mu | Not |
| ----- | ------------- | --- |
| Marka tanınıyor | <Tag tone="risk">Hayır</Tag> | Cevap verecek bir kitle yok |
| Rakip aktif hamle yapıyor | <Tag tone="risk">Hayır</Tag> | Rakipler İstoc'u tehdit görmüyor |
| İzlenecek olay akışı var | <Tag tone="warn">Kısmen</Tag> | Sektör grupları izlenebilir |
| Cevap üretecek kapasite var | <Tag tone="risk">Hayır</Tag> | 3 kişi, likidite kurmakla meşgul |
| Kanıt üretecek veri var | <Tag tone="risk">Hayır</Tag> | İşlem verisi yok |

**Sonuç:** Kontrgerilla sistemi bugün kurulursa, tetiklenecek olayı olmayan bir alarm sistemi
olur. Uygun zamanı, İstoc'un ilk 200 işlemini tamamlayıp sektörde konuşulmaya başladığı andır.

## Bugünden kullanılabilecek üç parça

Çerçevenin tamamı erken; ancak üç bileşeni **bugün doğrudan değer üretir**.

### 1. Aşılama (L2 seviyesi)

Satıcı itirazları öngörülebilir. Bunları görüşmede duymadan önce içerikle cevaplayın.

| Beklenen itiraz | Aşılama içeriği |
| --------------- | --------------- |
| "Komisyon çok" | Komisyonun neyi satın aldığını gösteren toplam maliyet sayfası |
| "Müşterimi görürler" | Gizli fiyat ve kapalı katalog özelliğinin anlatımı |
| "Ürün yüklemek zahmetli" | "Sizin yerinize yükleyelim" hizmetinin somut anlatımı |
| "Param gelmez" | Ödeme akışı ve emanet mekanizmasının adım adım anlatımı |
| "Zaten müşterim var" | Kapasite fazlası ve ölü sezon argümanı |

### 2. Kapasite kapısı kuralı

Talep artıran hiçbir hamle, o talebi karşılayacak arz yokken başlatılmaz. İstoc için bu kural
şu anlama gelir: **bir kategoride 20 aktif satıcı yoksa, o kategoriye alıcı çekmeyin.**
Bu tek kural, "boş dükkâna müşteri getirme" hatasını yapısal olarak engeller.

### 3. Sessizlik disiplini

Her olaya cevap vermek zorunda değilsiniz. Küçük ekipte en kıt kaynak dikkattir; sessizlik
onu korur. Karşılık merdiveninin L0 ve L1 seviyeleri bugünden uygulanabilir:
[Karşılık merdiveni](/istocpazar2/karar-sistemi/karsilik-merdiveni/).

## Levinson ilkelerinin İstoc karşılığı

| İlke | Soğuk başlangıçtaki karşılığı |
| ---- | ----------------------------- |
| Bağlılık | Kategori kararını 90 gün değiştirmeyin |
| Yatırım | Reklam değil, arz kurulumuna yatırım yapın |
| Tutarlılık | Her satıcıya aynı vaadi verin; özel istisna kaydedin |
| Güven | Kanıt üretin: gerçek işlem, gerçek referans |
| Sabır | İlk işlem 90 günü bulabilir; eşiği buna göre koyun |
| Araç çeşitliliği | Reklam tek araç değil; ürün, operasyon ve fiyat da araçtır |
| Satış sonrası | İlk işlemden sonraki 7 gün, ilk temastan önemlidir |
| Kolaylık | Ürün yükleme zahmetini siz üstlenin |
| Şaşırtma | Sürpriz değil, **beklenmedik hız** kullanın: 2 saatte teklif |
| Ölçüm | Kayıt değil, tekrar eden eşleşme ölçün |
| Katılım | İlk 50 satıcıyı "kurucu satıcı" olarak sürece dahil edin |
| Bağımlılık | Oda, dernek, site yönetimiyle karşılıklı ilişki kurun |
| Teknoloji | Otomasyondan önce elle çalışan süreç kurun |
| İzin | Toplu mesaj yerine izinli iletişim; hukuki zorunluluk |
| İçerik | Her iddianın arkasında doğrulanabilir kanıt olsun |
| Geliştirme | Her hafta bir varsayımı test edin |
