## Öncü ve ardıl ayrımı

<Aside type="caution" title="Neden bu ayrım önemli">
**Öncü gösterge** bugünkü çabayı ölçer ve günlük değiştirilebilir. **Ardıl gösterge** dünkü
çabanın sonucunu gösterir ve bugün değiştirilemez. Ekip günlük olarak öncü göstergeleri
konuşmalı, aylık olarak ardıl göstergeleri değerlendirmelidir.
</Aside>

| Öncü göstergeler | Ardıl göstergeler |
| ---------------- | ----------------- |
| Temas sayısı | Tamamlanmış işlem |
| Nitelikli randevu | Gelir |
| Ziyaret sayısı | Tekrar eden alıcı |
| İlk teklif süresi | Ortalama satış döngüsü |
| Cevapsız talep | Aktif satıcı sayısı |
| Kurumsal görüşme | İş birliği geliri |
