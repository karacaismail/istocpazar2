## Katman katman

### Amaç (değişmez)

> İSTOÇ ve çevresindeki toptan ticareti dijital, karşılaştırılabilir ve güvenli hale getirmek.

Bu cümle yıllarca değişmez. Strateji değişir, amaç değişmez.

### Yıllık hedef

> Kendini finanse eden, tekrar eden işlem üreten çalışan bir pazar yeri kurmak.

<Aside type="tip" title="Anahtar kelime: tekrar eden">
"Çok işlem" değil, **tekrar eden işlem**. Tek seferlik işlemler bir pazar yeri kurmaz;
bir aracılık şirketi kurar. Ayrıntı: [Likidite](/istocpazar2/pazaryeri/likidite/).
</Aside>

### 90 gün hedefi

| Gösterge | Hedef | Neden bu sayı |
| -------- | ----- | ------------- |
| Aktif satıcı | 20 | Atomik ağ eşiği tahmini |
| Tamamlanmış işlem | 15 | Kanıt üretmeye yeter |
| Tekrar eden alıcı | 3 | Ağın çalıştığının ilk işareti |
| Aylık gelir | 1 kişilik maliyeti karşılıyor | Kendini ödeme yolunda ilk basamak |
| Medyan ilk teklif süresi | 2 saat altı | Telefonla rekabet edebilme eşiği |

## Hedef olmayanlar

<Aside type="danger" title="Bilinçli olarak hedef yapılmayanlar">
| Sayı | Neden hedef değil |
| ---- | ----------------- |
| Kayıtlı satıcı sayısı | Ölü kayıt üretir, alıcıyı kaçırır |
| Sosyal medya takipçisi | İşlemle ilişkisi yok |
| Sitede geçirilen süre | B2B'de kısa süre iyidir |
| Ürün ilanı sayısı | Güncelliği olmayan ilan zarardır |
| Gönderilen mesaj sayısı | Çıktı değil, girdi |
| Ziyaret sayısı | Sonuç değil, faaliyet |
| Etkinlik sayısı | Takipsiz etkinlik değersizdir |

Bunlar **izlenir** ama hedeflenmez. Fark önemlidir: izlenen sayı bilgi verir,
hedeflenen sayı davranış değiştirir. Ayrıntı:
[Goodhart tuzağı](/istocpazar2/olcum/goodhart/).
</Aside>

## Hedeflerin çelişmemesi

Hedefler birbirini baltalayabilir. Kontrol edilmesi gereken çelişkiler:

| Hedef A | Hedef B | Çelişki | Çözüm |
| ------- | ------- | ------- | ----- |
| Çok satıcı | Yüksek arz kalitesi | Hızlı toplama kaliteyi düşürür | Aktif satıcı hedefi, kayıtlı değil |
| Çok talep | Yüksek cevap oranı | Talep arzı aşarsa cevapsız kalır | Kapasite kapısı |
| Hızlı büyüme | Kendini ödeme | Büyüme nakit yer | Aşamalı istihdam |
| Yüksek komisyon | Satıcı memnuniyeti | Komisyon direnç yaratır | Hizmet geliri ile dengeleme |
| Çok etkinlik | Takip kalitesi | Kapasite yetmez | Ayda 1 etkinlik |

## Hedeflerin gözden geçirilmesi

| Katman | Değişme sıklığı |
| ------ | --------------- |
| Amaç | Yıllarca değişmez |
| Yıllık hedef | Yılda bir |
| 90 gün hedefi | Çeyrekte bir, kapı toplantısında |
| Aylık hedef | Ayda bir, gerçek veriye göre |
| Haftalık hedef | Haftada bir |
| Günlük çıktı | Gerektiğinde |

<Aside type="caution" title="90 gün sabitleme kuralı">
90 gün hedefi, çeyrek içinde **değiştirilmez**. Değiştirilirse ekip neye koştuğunu bilemez
ve hiçbir varsayım test edilemez. Yeni fikir çıkarsa bir sonraki çeyreğe yazılır.
</Aside>
