## Kural: semptom kök neden değildir

"Satıcı gelmiyor" bir semptomdur. Sebebi olabilecek en az dokuz farklı kök neden vardır ve
bunların hepsi farklı çözüm gerektirir. Yanlış kök nedene doğru çözüm uygulamak, hiçbir şey
yapmamaktan pahalıdır; çünkü hem para hem zaman hem de ilk izlenim harcanır.

## Kök neden kataloğu

Her satır bir hipotezdir. Sağdaki sütun, o hipotez doğruysa **hangi çözümün işe yarayacağını**
gösterir. Dikkat edin: sekiz satırdan yalnızca ikisinin çözümü pazarlamadır.

| Kod | Kök neden | Doğruysa çözüm nerede | Test yöntemi |
| --- | --------- | --------------------- | ------------ |
| A1 | Satıcı dijital satış istemiyor | İş modeli / segment değişimi | 20 satıcı görüşmesi |
| A2 | Fiyatını rakibe göstermek istemiyor | Ürün: gizli fiyat, RFQ modeli | Fiyat görünürlüğü A/B testi |
| A3 | Ürün yüklemek zahmetli | Operasyon: yerine biz yükleyelim | Elle yükleme teklifi kabul oranı |
| A4 | Komisyon oranını kabul etmiyor | Fiyatlama / iş modeli | Komisyonsuz pilot |
| T1 | Alıcı yeterli tedarikçi bulamıyor | Arz yoğunluğu (kategori daraltma) | Arama sonucu doluluk ölçümü |
| T2 | Mevcut kanal (telefon/WhatsApp) yeterli | Değer önerisi baştan yanlış | "Neden platform" görüşmesi |
| T3 | Tanımadığına para göndermiyor | Güven mimarisi (escrow, KYB) | Escrow'lu vs escrow'suz dönüşüm |
| T4 | Marka bilinmiyor | **Pazarlama** | Marka bilinirlik anketi |
| P1 | B2B katalog değil RFQ ister | Ürün: RFQ öncelikli akış | RFQ vs katalog dönüşümü |
| P2 | Kategori çok geniş, hiçbiri derin değil | Kapsam daraltma | Kategori bazlı doluluk |
| P3 | Satıcı emeğinin karşılığını görmüyor | Ürün: sihirli an tasarımı | İlk 14 gün satıcı davranışı |
| P4 | Talep ile arz eşleştirilmiyor | Ürün: eşleştirme motoru | Elle eşleştirme pilotu |

<Aside type="caution" title="Bu tablonun en önemli satırı">
**T2** satırıdır. Eğer alıcılar mevcut kanallarından memnunsa, İstoc'un problemi soğuk
başlangıç bile değildir; **değer önerisinin baştan yanlış kurulmuş olmasıdır**. Bu ihtimal
ölçülmeden hiçbir bütçe bağlanmamalıdır. Ayrıntı:
[Tüketilmeyen pazar ve geçiş maliyeti](/istocpazar2/rekabet/tuketilmeyen-pazar/).
</Aside>

## Problemin hangi katmanda olduğu

Uzman yönergesinin istediği geniş seçenek uzayı. Her katman ayrı bir sahiplik gerektirir.

| Katman | İstoc için geçerlilik | Not |
| ------ | --------------------- | --- |
| Pazarlama | <Tag tone="warn">Kısmen</Tag> | Yalnızca T4 doğruysa birincil |
| Satış | <Tag tone="ok">Yüksek</Tag> | İlk 50 satıcı elle kazanılır, reklamla değil |
| Ürün | <Tag tone="ok">Yüksek</Tag> | Sihirli an, RFQ akışı, eşleştirme |
| Pazar yeri tasarımı | <Tag tone="ok">Yüksek</Tag> | Kategori genişliği, eşleştirme kuralları |
| Fiyatlama | <Tag tone="warn">Kısmen</Tag> | Komisyon direnci varsa birincil |
| Teşvik tasarımı | <Tag tone="ok">Yüksek</Tag> | Hangi taraf sübvanse edilecek |
| Güven | <Tag tone="ok">Yüksek</Tag> | B2B'de ödeme riski belirleyicidir |
| Arz | <Tag tone="ok">Yüksek</Tag> | Yoğunluk, genişlik değil |
| Talep | <Tag tone="ok">Yüksek</Tag> | Nitelikli alıcı, ziyaretçi değil |
| Likidite | <Tag tone="ok">Kritik</Tag> | Asıl ölçüt |
| Coğrafya | <Tag tone="ok">Yüksek</Tag> | İSTOÇ fiziksel kümesi bir avantaj olabilir |
| Dikey seçimi | <Tag tone="ok">Kritik</Tag> | Karar 1 |
| Dağıtım | <Tag tone="warn">Kısmen</Tag> | Kanal seçimi likiditeden sonra gelir |
| Ortaklıklar | <Tag tone="warn">Kısmen</Tag> | Oda, dernek, site yönetimi |
| Topluluk | <Tag tone="warn">Kısmen</Tag> | Mevcut WhatsApp grupları bir varlıktır |
| Etkinlik | <Tag tone="warn">Kısmen</Tag> | Organizatör rolünün dayanağı |
| Operasyon | <Tag tone="ok">Yüksek</Tag> | Elle yükleme, elle eşleştirme |
| Finansman | <Tag tone="info">Bilinmiyor</Tag> | Vade/finansman bir kanca olabilir |
| İş modeli | <Tag tone="warn">Kısmen</Tag> | Komisyon mu abonelik mi lead mi |
