## Sürümleme kuralı

| Değişiklik tipi | Sürüm etkisi |
| --------------- | ------------ |
| Yazım ve biçim düzeltmesi | Yama (0.1.x) |
| Yeni sayfa veya bölüm | Küçük (0.x.0) |
| Bir öneri veya teşhisin değişmesi | Küçük, günlükte ayrı başlık |
| Stratejinin temelden değişmesi | Büyük (x.0.0) |

<Aside type="caution" title="Silme yasağı">
Bir varsayım çürüdüğünde ilgili sayfa **silinmez**. Üzerine karşı kanıt eklenir ve bu
günlüğe yazılır. Böylece "neden fikir değiştirdik" sorusunun cevabı kayıtta kalır.
Fikir değiştirmenin kaydı, fikrin kendisinden değerlidir.
</Aside>

## 0.2.0 — Kararlar geldi, sayılar yeniden hesaplandı

**Neden değişti:** Sahibi üç girdi verdi — gerçek kategori kümesi (plastik, züccaciye,
oyuncak, cam), satıcı önceliği ve 90 gün hedefi (100+ aktif satıcı). Ayrıca dil geri
bildirimi geldi: Türkçe metnin içine İngilizce terim doldurulmuş.

**Verilen kararlar**

| Karar | Sonuç | Kim verdi |
| ----- | ----- | --------- |
| Kategori | Çekirdek plastik, ikinci halka züccaciye, oyuncak sezonluk | Sahibi |
| 90 gün hedefi | 100+ aktif satıcı (pasifler ayrıca) | Sahibi |
| Sübvansiyon | Satıcı tarafı; parayla değil emek ve talep ile | Rehber |
| Ekip sıralaması | Organizatör → **Saha** → Masa Başı | Rehber |

**Değişen görüşler**

| Konu | 0.1.0 | 0.2.0 | Neden |
| ---- | ----- | ----- | ----- |
| Kategori tercihi | Yüksek sepetli kategori (proje aydınlatma) | Yüksek tekrarlı kategori (plastik) | Gerçek kategori kümesi öğrenildi; kaldıraç değişti |
| Alıcı personası | Proje müteahhidi | E-ticaret satıcısı + ev eşyası perakendecisi | Kategoriye uygun alıcı farklı |
| Coğrafya | Tek coğrafya | Asimetrik: arz İSTOÇ, talep Türkiye geneli | E-ticaret satıcısı dijital erişilir |
| Ekip sıralaması | Organizatör → Masa Başı → Saha | Organizatör → Saha → Masa Başı | 100 satıcı hedefinde darboğaz saha kapasitesi |
| Atomik ağ | 20 satıcı, 60 alıcı | 100 aktif satıcı, 60 alıcı, ayda 55 talep | Hedef sahibince yükseltildi |
| Ortalama işlem tutarı | 40.000 TL | 25.000 TL | Kategoriye uygun düzeltme |
| Başabaş işlem sayısı | 150 / ay | 240 / ay | Sepet düştü |
| Aylık başabaş | 7. ay | 6. ay | Hizmet geliri büyüdü |
| Nakit çukuru | 393 bin TL | 309 bin TL | Daha çok satıcı = daha çok hizmet geliri |
| Sübvansiyon | "Sahibi karar versin" | Karar verildi: satıcı tarafı | Teknik tercih sahibine sorulmamalıydı |

**Eklenen**

- [Arz kurulum operasyonu](/istocpazar2/cozum/arz-kurulum-operasyonu/) — 100 satıcı hedefinin
  doğurduğu katalog yükleme darboğazı ve toplu içe aktarma zorunluluğu
- Satıcı başına iş yoğunluğu uyarısı: 100 satıcı + 55 talep = ayda 0,5 sipariş; 6. ayda
  talep 150'ye çıkmazsa satıcı kaybı başlar
- Aktif / yeni / uykuda / pasif / ölü satıcı sınıflaması ve görünürlük kuralları
- Terim ipucu balonu bileşeni: teknik terimin Türkçe karşılığı görünür, aslı ve açıklaması
  balonda

**Dil düzeltmesi**

Türkçe cümlelerin içine yerleşmiş İngilizce terimler Türkçeleştirildi:

| Eski | Yeni |
| ---- | ---- |
| wedge | giriş kaması |
| concierge model | elle yürütülen model |
| premortem | batış provası |
| postmortem | batış incelemesi |
| anti-pattern | hata kalıbı |
| North Star | Kuzey Yıldızı |
| escrow | emanet hesabı |
| churn | terk / satıcı kaybı |
| CAC | müşteri kazanım maliyeti |
| GMV | işlem hacmi |
| onboarding | uyum süreci |
| lead | aday müşteri |
| pivot | yön değişimi |
| kill criteria | durdurma ölçütü |

Gerçek jargon olanlar korundu; üzerlerine Türkçe açıklama balonu eklendi.

**Adres değişikliği**

İki sayfanın adresi değişti:
`pazaryeri/wedge-secenekleri` → `pazaryeri/giris-kamasi-secenekleri`,
`cozum/onerilen-wedge` → `cozum/onerilen-giris-kamasi`.

| Eksik | Neden |
| ----- | ----- |
